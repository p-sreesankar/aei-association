  PATH ALIASES
═══════════════════════════════════════════════════════════════════════════════

The following aliases are configured in vite.config.js:

  @              → src/
  @components    → src/components/
  @context       → src/context/
  @pages         → src/pages/
  @data          → src/data/
  @config        → src/config/
  @hooks         → src/hooks/
  @utils         → src/utils/
  @assets        → src/assets/

═══════════════════════════════════════════════════════════════════════════════
  ROUTING STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

Public Routes:
  /               → Home
  /about          → About
  /contact        → Contact
  /events         → Events (if enabled)
  /notices        → Notices (if enabled)
  /resources      → Resources (if enabled)
  /projects       → Projects (if enabled)
  /grievance      → Grievance (if enabled)
  /login          → Login page

Protected Routes (authenticated):
  /mock-tests                  → Mock test catalog
  /mock-tests/:testId          → Test quiz
  /mock-tests/:testId/results  → Test results

Admin Routes (admin only):
  /admin              → Admin dashboard
  /admin/manage-tests → Test management

Legacy Redirects (for backwards compatibility):
  /mock-test/*        → /mock-tests/*
  /mock-test/admin   → /admin
